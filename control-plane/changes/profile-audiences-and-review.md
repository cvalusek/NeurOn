# Clearer profile sharing, review, and connection details

- Profile Audience now has its own row and supports Only me, Everyone, or a
  team. Team members can publish profiles they own to teams they can use.
- New and edited profiles stay on a dedicated page with a floating Review
  action. The confirmation summarizes changes, timing, cost, selected model
  facts, LiteLLM aliases, and direct runtime IDs before anything is saved.
- Reservation connection details now separate the LiteLLM gateway from the
  direct model host and link to Client setup and the LiteLLM UI when configured.
- Assistant timing uses the same duration-button pattern as the rest of NeurOn,
  and saves now report through a temporary toast.
- Invitation copying has a browser-compatible fallback, and team membership
  editing has a clearer visual divider.
