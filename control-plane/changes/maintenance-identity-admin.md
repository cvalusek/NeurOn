# Identity administration during maintenance

- Maintenance mode continues to pause reservations, target changes,
  reconciliation, discovery, traffic polling, and provider activity while
  allowing safe account, invitation, role, team, and authentication repairs.
- The admin menu now separates Accounts, Teams, and Authentication. Accounts
  uses focused tabs for users, invitations, and duplicate merges; invitations
  open from an **Invite user** dialog. Authentication similarly separates
  existing methods from OIDC and GitHub setup.
- The HassleOff admin label is now simply **HassleOff**.
