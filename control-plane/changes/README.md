# Release notes

Add one short Markdown file for every operator- or user-visible control-plane change. The first heading is the update-screen title; the remaining text explains impact and any action an administrator should take.

Files remain in the repository. NeurOn reads only fragments changed between the running image revision and the latest successful image revision, so the Updates screen naturally shows the relevant set.

Use a descriptive kebab-case filename and do not include secrets, private hostnames, migrated data, or internal incident details.
